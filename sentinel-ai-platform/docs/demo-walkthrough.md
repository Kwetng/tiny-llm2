# Demo walkthrough (10 minutes)

A script for presenting this project to a technical and risk audience. Each step names the capability it demonstrates.

## 1. The one-line pitch (30 seconds)
> "This is the platform I would build in my first six months: one governed gateway that every AI use case in Capital Markets and Corporate Banking plugs into, so compliance is a property of the platform rather than a project per use case."

## 2. Show the gate (2 minutes)
Show `evals/reports/latest.md`, which has twelve release thresholds that block a merge. Point at three numbers:
- **Zero entitlement leaks:** a public-side trader asking about Project Heron gets nothing.
- **Indirect injection fully quarantined:** the planted vendor note never reaches the model.
- **All 7 direct attacks blocked**, including an encoded payload. The other 5 red-team prompts test quarantine, barrier probes and PII.

Then tell the story: *"On the first run the gate failed. The model answered a question about staff parking permits with an unrelated sentence, because generic words like 'bank' and 'policy' matched. The fix was to stop generic words counting as evidence. That's exactly why the gate exists."*
*Capabilities shown: evaluation, responsible AI, audit readiness.*

## 3. Show an answer and a refusal (2 minutes)
```bash
uvicorn sentinel.gateway:app
curl -s localhost:8000/v1/ask -H "Authorization: Bearer tok-alice" -H "Content-Type: application/json" \
  -d '{"question": "What leverage is outside the bank'"'"'s appetite?"}'
curl -s localhost:8000/v1/ask -H "Authorization: Bearer tok-bob" -H "Content-Type: application/json" \
  -d '{"question": "What is the margin on the Project Heron term loan B?"}'
```
The first answer cites `[CP-001 §3.2]`; the second abstains. Explain that entitlements are enforced *before* retrieval (ADR 0002), because the LLM is never the security boundary.
*Capabilities shown: RAG pipelines, access control, secure context injection.*

## 4. Show the audit chain (1 minute)
Call `GET /v1/audit/verify` as `tok-erin`, internal audit. Then explain: *"Every event carries the hash of the previous one. Edit a single record and verification points to the exact line. In production the same records go to immutable storage, which the Terraform provisions."*
*Capabilities shown: audit logging.*

## 5. Show document intelligence (1 minute)
Call `GET /v1/extract/csa` as `tok-frank`:
- CSA-001's threshold and minimum transfer amount come from the amendment, with lineage to both documents.
- The loosely worded CSA-003 goes to human review with five reasons.

*Capabilities shown: document intelligence and GenAI applications, with your ISDA/CSA domain depth.*

## 6. Show the agent's limits (1 minute)
The covenant-breach workflow drafts the escalation and stops at *awaiting approval*. The requester can't approve their own action, and unsupported tasks ("transfer 5 million") are refused.
*Capabilities shown: agentic workflows and orchestration, human oversight.*

## 7. Show the cloud and the pipeline (1.5 minutes)
- **Terraform:** Azure (OpenAI private endpoint with no API keys, customer-managed keys, AI Search, immutable audit storage) and GCP (VPC Service Controls, CMEK, Vertex endpoint, Cloud Run internal only). Checkov: 73 checks passed, none failed.
- **CI:** tests, evaluation gate, Bandit, dependency audit, secret scanning, Terraform validate, Checkov.

*Capabilities shown: Azure and GCP, infrastructure-as-code, DevSecOps.*

## 8. Close on governance and leadership (1 minute)
- `governance/evidence_pack.md` is generated by CI and maps to SS1/23 principles 1–5.
- `governance/control_mapping.md` shows one control meeting many frameworks.
- `docs/operating-model.md` covers the team, RACI and 90-day plan.

> "The build is the easy part. What makes it work in a bank is that Model Risk trusts the evidence and the business trusts the answers."

## Likely questions, and short answers
- **"Is this production-ready?"** No. It's a reference implementation that runs locally with a deterministic model, and the Terraform has been validated but not deployed here. The controls, interfaces and evidence flow are the real point.
- **"Why a local model in the gate?"** It makes the gate fast, free and reproducible. Hosted models must pass the same gate before being enabled (ADR 0004).
- **"What's the biggest residual risk?"** Mislabelled source documents, because entitlements are only as good as their labels. The mitigations are owner attestation and labels shown in citations.
